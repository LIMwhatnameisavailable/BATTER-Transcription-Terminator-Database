细菌转录终止子数据库（BTED）—— 静态演示骨架

本页面是 BTED 项目的 GitHub Pages 演示站点骨架。当前版本只提供项目说明与书目级元数据目录，不包含任何记录级数据、坐标信息或科学结论。

项目目的

BTED（Bacterial Transcription Terminator Database）项目旨在从已公开发表的文献中系统整理细菌转录终止相关的实验测序数据（Term-seq、Rend-seq、dRNA-seq 等），构建可检索、可追溯的细菌转录终止子数据库及配套网站。

数据溯源基于 BATTER 工具论文（Jin, Cui, Liu et al., Microbiome, 2026）Table S1 所列的 13 篇原始文献。这 13 篇文献的数据库登录号已经逐篇人工核查，汇总于仓库根目录的 accession_list_verified.csv。

证据边界

  • 本站处于骨架阶段：不展示任何记录级条目、基因组坐标或证据类别标签。
  • 记录级证据分层标准（SOP）尚未完成定义与评审。在该标准获批之前，本站不对任何记录作出证据层级声明，也不区分任何记录的效力等级。
  • 部分来源文献的补充表中混有计算预测子表（如 TransTermHP、ARNold、RhoTermPredict 的输出）。这些内容由各原文献自行标注；本项目尚未完成逐条记录的证据审核。
  • BATTER 论文配套的 Zenodo 仓库（DOI: 10.5281/zenodo.16761763）内容为模型代码、训练数据与全基因组预测结果，与本项目整理的文献来源数据不是同一类内容。本站任何位置提及该仓库时，均将其标注为预测产物。

范围说明

  • 当前已核实范围：13 篇来源文献（PMID 清单见数据目录），按 BATTER Table S1 口径覆盖约 20 个物种/菌株、22 条数据记录。
  • 口径提醒：13 篇是论文数，22 条是 Table S1 中这些论文下的来源/物种数据记录数，两者单位不同、不混写。本地工作树的 22 条来源注册表已作为元数据迁移到本仓库，展示于来源目录。
  • 站点版本：静态骨架 v0.1（2026-08-07）。在元数据 schema 与证据口径通过评审之前，站点内容将保持在骨架阶段。

数据来源声明

  • 数据目录仅由仓库内已核实的 accession_list_verified.csv 派生，展示书目级元数据（PMID、物种/菌株、期刊年份、数据库名称、登录号/DOI、数据类型）。
  • 原始测序数据保存在 GEO、SRA、ENA、ArrayExpress、PRIDE、Figshare 等公开数据仓库中，本站只链接、不复制。
  • 出版商补充材料工作簿按其来源以文献 DOI 引用，不复制进本站。
  • 本地 BTED 工作树的来源注册表（22 条来源记录的元数据）已迁移至 data/registry/ 并展示于来源目录；其标准化坐标输出与 JBrowse 资源尚未迁移，须按验收门槛逐来源审计后方可公开。详见方法与局限。

局限性

  • 本站没有记录级数据：坐标体系（0-base/1-base、单点/区间）与逐来源参考基因组版本对齐均未定稿。
  • 目录表中的"数据类型"列为文献或数据仓库的自述测定类型，不代表本项目的证据分层结论。
  • 13 篇来源的核心补充表虽均确认包含坐标字段，但存在筛选口径差异、混合表内容与小幅行数差异，尚不能据此对表内每条记录作统一的证据判断。
  • 站点为纯静态页面，无服务端数据库；当前版本不含客户端搜索/过滤功能（纯 HTML + CSS 骨架）。
