# data/audit — 审计摘要（可公开）

本目录存放证据分层判断、来源间冲突、排除与回退记录的**公开审计摘要**。这些摘要用于解释“为什么某个来源被排除/拆分/标记为 blocked”，以及“为什么预测或混合证据没有进入公开层”。

## 放什么

- 混合证据表（`author_integrated_mixed_evidence`）的处理说明与排除理由；
- 纯预测结果（`prediction_only`）的排除记录；
- 坐标体系、参考版本、链方向冲突的判定依据；
- 来源状态变为 `blocked` 的原因与恢复条件；
- 统计口径或命名争议的裁决记录。

## 不放什么

- **不放私密资料**：实验室内部分析细节、未脱敏样本信息、个人备注、本地路径；
- **不放原始测序数据或出版商工作簿**；
- **不放计划公开但尚未审计的端点数据**（那是 `data/public/` 的位置）。

私密或敏感的审计材料应保留在贡献者本地工作环境的私有 `audit/` 目录中，不进入 GitHub。

## 记录格式

每条审计记录建议包含：

1. 来源/端点 ID；
2. 发现方式；
3. 影响范围；
4. 处理决定；
5. 解决证据；
6. 剩余风险。

已解决的问题保留原记录，不删除。

## 示例

> **BATTER_S1_020 混合证据拆分**：作者 Supplementary Table S2D（Nanopore native RNA 3′ ends，1,165 条）作为 `author_called_endpoint` 进入实验层；S2B（ARNold 预测）与 S2C（RhoTermPredict 预测）因属于纯预测，保留为内部审计记录，不进入公开数据库。
