# data/audit —— 证据审计与排除记录（内部）

本目录留档证据分层判断、来源间冲突、排除与回退记录，供内部审计与溯源使用，不作为公开数据库内容发布。

## 放什么

- 混合证据表（`author_integrated_mixed_evidence`）的内部处理说明；
- 纯预测结果（`prediction_only`）的排除记录与理由；
- 坐标体系 / 参考版本 / 链方向冲突的判定依据与解决记录；
- 来源被标记为 `blocked` 的原因、影响范围与恢复条件。

问题记录遵循"发现方式 — 影响 — 处理决定 — 解决证据 — 剩余风险"的格式；已解决的问题不删除原记录。

## 不放什么

- 不放原始测序数据或出版商工作簿（只引用登录号 / DOI）；
- 不放任何计划公开但尚未审计的端点数据（那是 `data/public/` 的位置）。
