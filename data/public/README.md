# data/public —— 可公开标准化数据（预留）

本目录预留给未来可公开下载的小型、已审计标准化数据（端点 TSV/BED、公开元数据 JSON 等）。

## 进入本目录的条件（须同时满足）

1. 来源处理状态为 `published`（下载、文档、版本与校验齐全）；
2. 内容属于公开实验端点层（`author_called_endpoint` 或按公开规则调用的 `called_endpoint`），不含预测或混合证据；
3. 坐标体系、参考组装、contig 与链方向已完成核查，并写入该来源的处理记录；
4. 许可证与再分发条款检查通过；
5. 单文件体积适合 git 托管；大文件改用 Zenodo 等外部托管，本目录只放说明与指针。
