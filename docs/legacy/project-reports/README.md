# project-reports — 早期项目报告

本目录保存 BTED 项目早期形成的过程日志和核查报告，用于追溯当时的资料搜集与判断过程。

- `PROGRESS.md`：早期工作日志；
- `data_verification_report.md`：逐篇补充材料核查记录；
- `report_BATTER_supplementary.md`：BATTER 补充材料审查；
- `report_zenodo_and_documents.md`：Zenodo 与相关文档审查。
- `PMID_38030608_supplementary_data_1to5_findings.md`：该论文五份补充工作簿的早期结构核查报告，从被移除的重复原目录中单独保留。

这些文件不是当前数据发布接口。当前来源状态以 `data/registry/`、`docs/sources/`、`docs/standards/` 和版本发布说明为准。
