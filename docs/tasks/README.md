# BTED Branch Tasks

These tasks are intentionally small, reviewable units of work. Work only on the named branch, never push directly to `main`, and open a draft pull request when the task is complete.

Task order:

1. `01-reconcile-current-bted-state.md` — document the gap between this repository and the current BTED working state.
2. `02-github-pages-demo.md` — build a static demo only after Task 01 is reviewed.

Every task must preserve primary-source evidence, avoid API keys and private data, and state exactly what was not changed.
