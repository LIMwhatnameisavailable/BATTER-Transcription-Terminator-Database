# GitHub Pages 演示站点计划

**任务：** 01 交付物 —— 仅为计划。站点本身在 Task 02 中构建，前提是本计划与迁移盘点通过评审。
**日期：** 2026-08-07

---

## 1. 范围与硬边界

一个小型、静态、可评审的 BTED 数据库演示，作为项目站点部署在 `/<仓库名>/` 路径下。

- GitHub Pages **仅是静态托管**：**没有服务端数据库、没有服务端代码、也无法访问私有数据**。任何搜索/过滤都在客户端对一个生成的公开元数据文件进行。
- 演示只暴露**经批准的公开元数据与小型派生资产**。原始测序数据与出版商工作簿绝不进入 Pages 产物；站点通过 `accession_list_verified.csv` 中已核实的登录号链接到 GEO/SRA/ENA/ArrayExpress/Figshare/PRIDE/Zenodo。
- 站点上的每条科学声明都链接到仓库文档或一手来源。任何依赖外部 BTED 工作状态的内容在核实之前一律缓建（见 `docs/current-bted-status.md`）；站点不得制造占位性的科学声明。
- 站点绝不把仅预测或混合证据的记录标记为实验验证过的 endpoint。BATTER 全基因组预测（Zenodo `TES.bed.gz`）若被提及，必须明确标注为预测结果。

## 2. 页面地图

1. **首页**（`index.html`）
   - 项目目的：基于 13 篇已核实来源文献构建实验支持的细菌转录终止子数据库。
   - 证据边界与范围声明；来源数量/版本严格按已批准口径展示（当前：13 篇文献已核实，见 `data_verification_report.md`）。
   - 局限性摘要及指向方法页的链接。
2. **数据目录**（`catalog/`）
   - 由一个**经批准的**元数据文件生成的静态、客户端可搜索/过滤的表格（见第 3 节）。
   - 列仅限于已核实的元数据：PMID、物种/菌株、实验方法类型、登录号、坐标文件状态、引用/DOI。
3. **记录页模板**（`records/<pmid>.html`，每个来源一页，或有文档说明的模板）
   - 物种、实验方法、参考基因组、证据类别（仅在 SOP 获批后）、状态、公开下载链接、引用、外部来源链接。
   - 由同一份经批准的元数据文件生成；不手写逐条记录的声明。
4. **方法 / 局限性**（`methods/`）
   - 坐标体系约定与未决的标准化决策（链接 `docs/current-bted-status.md`）、获批后的证据分层定义、排除项、可复现性链接。
5. **可选的 JBrowse 链接**
   - 仅在相应公开 JBrowse 配置与资产核实后添加（目前为 `to verify`）。若 Task 02 时仍未核实，则完全不放该链接，而不是放占位符。

## 4. 外部原始数据链接

站点只链接、绝不复制：

- 逐来源原始数据：`accession_list_verified.csv` 中的登录号（GEO/SRA/ENA/ArrayExpress/Figshare/PRIDE/GenBank）。
- BATTER 模型产物：Zenodo DOI 10.5281/zenodo.16761763，按 `report_zenodo_and_documents.md` 标注为训练数据/预测结果。
- 出版商补充文件：按来源以 DOI 引用。

所有出站链接在验证阶段检查（第 6 节）。

## 5. 部署方案

- 站点源码放在 Task 02 分支的专用目录（如 `site/`）；用 GitHub Actions 工作流构建**专用静态产物**并部署到 Pages。不直接从实验性工作目录部署。
- 所有资产与链接路径均为**相对路径**，在项目子路径 `/<仓库名>/` 下有效；绝不假设从 `/` 提供服务。
- 大型原始输入保持在产物之外；若有意外的大文件/二进制文件进入产物，工作流应失败（大小检查步骤）。
- 部署产物中不得有凭据、令牌、未发表数据、本地绝对路径或缓存目录。

## 6. 验证计划（Task 02）

1. 运行已接受的迁移所提供的任何回归测试（本仓库目前尚无）。
2. `git diff --check` 干净。
3. 在 `/<仓库名>/` 子路径下本地起服务（如 `python3 -m http.server` 加路径前缀，或等效静态服务器）并验证：
   - 首页在子路径下可加载；
   - 目录搜索/过滤在客户端可用；
   - 所有内部链接为相对路径且可解析；
   - 至少一个记录页正常渲染；
   - JBrowse 链接仅在已核实时存在且可加载；
   - 出站登录号/DOI 链接返回成功（抽查）；
   - 没有任何页面把预测或混合证据标记为实验性 endpoint；
   - 产物大小与文件类型扫描确认无原始数据、凭据或本地路径。
4. 在 draft PR 中附上截图与本地验证所用的确切命令。
