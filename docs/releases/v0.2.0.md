# BTED v0.2.0 发布说明

**构建日期：** 2026-08-10
**定位：** BATTER Table S1 自有数据的可公开演示版本。

## 发布规模

| 指标 | 数量 |
|---|---:|
| 来源记录 | 22 |
| 原始研究论文 | 13 |
| 公开标准化来源 | 21 |
| `audit_only` 来源 | 1（BATTER_S1_002） |
| 核心端点/整理记录 | 28,399 |
| 来源特异表 | 17 |
| `external_link_only` 来源特异字段 | 4 |
| JBrowse 配置 | 21 |

## v0.2.0 相比 v0.1 的变化

- 保留兼容的 24 列核心表，同时增加来源特异表和逐字段 `fields.json`；
- 为 21 个来源统一生成 BED6、manifest、checksum 和独立 JBrowse 配置；
- 建立许可登记，未核实再发布权的 Lalanne 来源不复制完整补充字段；
- S1_002 固定为 `audit_only`，不生成端点表或浏览器按钮；
- S1_020 公开包只含 S2D 实验端点，S1C 混合证据层不公开；
- S1_022 只公开作者 Term-seq TTS，纯 RhoTermPredict 表排除；
- 新增英文默认/中文切换的静态站点、22 个详情页和筛选目录；
- 小型逐来源下载随 Pages artifact 发布，使用稳定相对链接；
- 大型 JBrowse 资产从 Git 分离，作为 GitHub Release 压缩包发布。

## 发布资产

- `BTED-v0.2.0-data.tar.gz`：21 个公开数据目录和 1 个审计目录；
- `BTED-v0.2.0-jbrowse-assets.tar.gz`：JBrowse 4.3.0 runtime、21 份配置及来源前缀资产；
- 两个同名 `.sha256` 文件。

仓库内的 `data/public/v0.2.0/` 保留小型数据表和逐来源 checksum；大型浏览器文件不进入 Git。

## 验证结果

- 22 个来源、21 个公开来源、28,399 行和 21 个 JBrowse 配置均通过冻结计数；
- 24 列 schema、1-based/BED 转换、外键、校验和和证据边界通过；
- S1_005 两条染色体和所有来源前缀资产通过；
- 22 个详情页、21 个浏览器链接、中英文本和 Pages 完整产物通过；
- v0.1 回归测试保持通过。

工程审计样本见 `data/audit/v0.2.0/priority_source_audit.json`。

## 限制

- S1_002 仍无法从作者混合文件中可靠拆出可发布的纯端点层；
- v0.2.0 是演示发布，不是 DOI 长期归档；
- 原始测序、出版商工作簿和受限补充字段仅提供外部入口；
- 发布的是实验支持的 3′ end 数据及其作者/整理语境，不把所有条目称为逐位点功能确认的终止子。
