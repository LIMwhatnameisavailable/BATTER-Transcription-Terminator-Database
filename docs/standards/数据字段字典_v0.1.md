# BTED 数据字段字典 v0.1

本字典覆盖两个协作模板的全部列：来源登记表（26 列）与端点标准表（24 列），模板文件位于 `data/registry/templates/`。

**必填级别说明：**

- **登记必填**：来源登记（intake）阶段就必须填写；
- **条件必填**：满足条件时必填（如 pmid / doi 至少填一个）；
- **标准化前必填**：登记时可暂填 `NA`，但进入 `standardized` 状态前必须核实补齐；
- **发布前必填**：进入 `published` 状态前必须补齐；
- **可暂缓**：允许长期为 `NA`，视论文实际内容而定。

任何填写 `NA` 的列，都应在 `blocker_or_note` 或 `note` 中写明原因。

## 1. 来源登记表字段（external_literature_source_intake.tsv，26 列）

| 中文含义 | 英文字段名 | 是否必填 | 所属表 | 合法值 / 示例 | 备注 |
|----------|------------|----------|--------|----------------|------|
| 来源编号 | `source_id` | 登记必填 | 来源表 | `BTED_EXT_2026_001`；既有来源 `BATTER_S1_010` | 全库唯一；新来源用 `BTED_EXT_年份_三位序号`；`BATTER_S1_NNN` 编号不改 |
| 数据集短名 | `dataset_id` | 登记必填 | 来源表 | `ecoli-termseq-author-2024` | 小写英文短横线 slug；用于目录名与文件命名 |
| 论文标题 | `paper_title` | 登记必填 | 来源表 | 论文原文标题 | 按出版商页面原文抄录 |
| 发表年份 | `paper_publication_year` | 登记必填 | 来源表 | `2024` | 四位年份 |
| PubMed 编号 | `pmid` | 条件必填 | 来源表 | `29606352` | 纯数字；与 `doi` 至少填一个，都有都填 |
| DOI | `doi` | 条件必填 | 来源表 | `10.1016/j.cell.2018.04.027` | 不带 `https://doi.org/` 前缀 |
| 全文链接 | `pmc_or_fulltext_url` | 可暂缓 | 来源表 | PMC 或出版商全文 URL | 用于核对正文说法 |
| 物种 | `species` | 登记必填 | 来源表 | `Escherichia coli` | 拉丁学名，按论文原文 |
| 菌株 | `strain` | 登记必填 | 来源表 | `K-12 MG1655` | 论文未写明时填 `NA` 并在备注说明 |
| NCBI 分类号 | `taxonomy_id` | 可暂缓（标准化前必填） | 来源表 | `511145` | NCBI Taxonomy 的 taxid；注意区分物种与菌株层级 |
| 实验方法 | `assay` | 登记必填 | 来源表 | `Term-seq` / `Rend-seq` / `dRNA-seq` | 按论文方法部分的原始名称 |
| 主要证据类别 | `primary_evidence_class` | 可暂缓（标准化前必填） | 来源表 | `author_called_endpoint` / `called_endpoint` / `observed_signal` | 六层定义见证据分层文档；判不出填 `NA` 并标记 `to_review` |
| 样本或条件 | `sample_id_or_condition` | 登记必填 | 来源表 | `GSM2500127` 或 `M9 minimal, 37C` | 有 GSM 等编号优先写编号 |
| 原始数据登录号 | `raw_data_accessions` | 可暂缓 | 来源表 | `GSE95070; SRS2160682` | 多个用分号分隔；来自 Data Availability 声明 |
| 数据 / 补充表链接 | `raw_or_supplement_url` | 登记必填 | 来源表 | 出版商补充材料页或 GEO 页面 URL | 能直接定位数据的公开链接 |
| 端点来源文件 | `endpoint_source_file` | 登记必填 | 来源表 | `mmc3.xlsx (Table S3)` | 补充表文件名，含 sheet 名更好；未定位填 `NA` 并标记 `blocked` |
| 论文参考序列号 | `published_reference_accession` | 标准化前必填 | 来源表 | `NC_000913.3` | 论文实际使用的参考序列 accession，含版本号 |
| 参考组装 | `reference_assembly` | 标准化前必填 | 来源表 | `GCF_000005845.2` | NCBI Assembly 的 GCF/GCA 号，含版本号 |
| 参考序列 / contig 清单 | `reference_sequence_accession_or_contigs` | 标准化前必填 | 来源表 | `NC_000913.3`；多 contig 用分号分隔 | 必须与参考 FASTA header 逐字符一致 |
| 坐标体系 | `coordinate_convention` | 标准化前必填 | 来源表 | `1-based` / `0-based half-open` | 作者原始坐标的体系；判不出填 `NA` 并标记 `to_review` |
| 链方向定义 | `strand_definition` | 标准化前必填 | 来源表 | `+/- 表示转录本所在链` | 写清作者编码的确切含义 |
| 许可 / 复用说明 | `license_or_reuse_note` | 发布前必填 | 来源表 | `CC BY 4.0` 或条款出处 | 记录数据与补充表的许可 |
| 处理状态 | `processing_status` | 登记必填 | 来源表 | `to_review` / `accessible` / `standardized` / `curated` / `published` / `blocked` | 六状态定义见 SOP 第 8 节 |
| 整理人 | `curator` | 登记必填 | 来源表 | GitHub 用户名 | 便于评审时联系 |
| 登记日期 | `intake_date` | 登记必填 | 来源表 | `2026-08-07` | YYYY-MM-DD |
| 阻塞原因 / 备注 | `blocker_or_note` | 登记必填 | 来源表 | `NA` 或问题描述 | 缺失信息、疑点、恢复条件都写这里；无问题填 `NA` |

## 2. 端点标准表字段（external_literature_endpoint_schema.tsv，24 列）

| 中文含义 | 英文字段名 | 是否必填 | 所属表 | 合法值 / 示例 | 备注 |
|----------|------------|----------|--------|----------------|------|
| 端点唯一编号 | `end_id` | 必填 | 端点表 | `BTED_EXT_2026_001_GSM8123456_NC_000913.3_F_000001` | 构成：`source_id + sample_id + contig + strand + 序号` |
| 来源编号 | `source_id` | 必填 | 端点表 | `BTED_EXT_2026_001` | 必须与来源登记表中的 `source_id` 一致 |
| 样本编号 | `sample_id` | 必填 | 端点表 | `GSM8123456` | 端点归属的样本 / 条件 |
| 实验方法 | `assay` | 必填 | 端点表 | `Term-seq` | 与来源表一致 |
| 证据类别 | `evidence_class` | 必填 | 端点表 | `author_called_endpoint` / `called_endpoint` / `observed_signal` / `curated_record` / `author_integrated_mixed_evidence` / `prediction_only` | 后两类仅内部审计，不公开发布 |
| 作者端点编号 | `author_endpoint_id` | 条件必填 | 端点表 | 作者表中的 ID；无则 `NA` | 原样抄录，不改写 |
| 论文参考序列号 | `published_reference_accession` | 必填 | 端点表 | `NC_000913.3` | 与来源表一致 |
| 参考组装 | `reference_assembly` | 必填 | 端点表 | `GCF_000005845.2` | 与来源表一致 |
| contig 名称 | `reference_name` | 必填 | 端点表 | `NC_000913.3` | 与参考 FASTA header 逐字符一致；BED chrom / GFF3 seqid 同此 |
| 复制子标签 | `replicon_label` | 可暂缓 | 端点表 | `chromosome` / `plasmid pXO1` | 便于阅读，不替代 accession |
| 生物学坐标（1-based） | `biological_coordinate_1based` | 必填 | 端点表 | `4186653` | 正整数，范围 `[1, contig_length]`；BTED 统一 1-based |
| BED 起点（0-based） | `bed_start_0based` | 必填 | 端点表 | `4186652` | 恒等于 `biological_coordinate_1based - 1` |
| BED 终点（0-based） | `bed_end_0based` | 必填 | 端点表 | `4186653` | 恒等于 `biological_coordinate_1based`（单碱基 BED） |
| 链 | `strand` | 必填 | 端点表 | `+` / `-` | 统一转成这两个符号 |
| 信号值 / 分数 | `signal_or_score` | 可暂缓 | 端点表 | `137.5` | 作者 score、coverage 或信号值，原样数值 |
| 作者分类 | `author_category` | 可暂缓 | 端点表 | `Class I TTS` | 作者的 TTS class、终止子类型等原样标签 |
| 关联基因 / 位点 | `associated_gene_or_locus` | 可暂缓 | 端点表 | `b0058 / lptD` | 基因名或 locus tag |
| PubMed 编号 | `pmid` | 必填 | 端点表 | `29606352` | 便于端点级回溯文献 |
| DOI | `doi` | 条件必填 | 端点表 | `10.1016/j.cell.2018.04.027` | 与 pmid 至少一个非 `NA` |
| 来源表 / 文件 | `source_table_or_file` | 必填 | 端点表 | `mmc3.xlsx (Table S3)` | 端点出自哪个文件哪张表 |
| 坐标解释 | `coordinate_interpretation` | 必填 | 端点表 | `作者坐标为 0-based 起点，已 +1 转为 1-based 单碱基 3′ end 位置` | 写清从作者坐标到 BTED 坐标的转换规则 |
| 原始行引用 | `original_row_reference` | 必填 | 端点表 | `row 1523` 或作者表主键 | 任何人能据此查回作者原始表的对应行 |
| 质控状态 | `qc_status` | 必填 | 端点表 | `pass` / `to_review` / `blocked` | 端点级质控结论 |
| 备注 | `note` | 可暂缓 | 端点表 | `NA` 或补充说明 | 作者预测字段等信息写这里并注明性质 |

## 3. 通用约定

- 缺失信息一律填 `NA`，不留空、不编造；
- 多值字段用分号分隔；
- 所有日期用 `YYYY-MM-DD`；
- accession 号带版本号（如 `NC_000913.3` 而非 `NC_000913`）；
- 作者原始表的列原样保留在冻结副本中，标准表只追加、不覆盖。
