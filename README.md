# 背景说明

我正在实习期间参与一个数据整理项目，需要你帮我核查/审视接下来的技术方案是否合理。
以下是客观背景信息：

## 相关文献信息

1. Jin, Cui, Liu et al. 发表于 Microbiome 期刊（2026年）的论文，介绍了一个名为
   BATTER 的工具，用于预测细菌的转录终止位点（Rho依赖型和Rho非依赖型）。
   该论文的 Supplementary Table S1 列出了13篇提供真实实验验证数据
   （Term-seq / Rend-seq / dRNA-seq 等测序方法）的原始文献，覆盖约27个
   细菌物种条目。论文配套的 Zenodo 仓库仅包含模型代码、训练数据和预测结果，
   不含这13篇文献的原始实验坐标数据。

2. Kosiński et al. 发表于 Nucleic Acids Research 期刊（2025年）的论文，
   介绍了一个名为 TERMITe 的方法/工具，用于基于 Term-seq 数据系统性识别
   细菌内在转录终止子。该论文构建了覆盖13个细菌物种、17个数据集的终止子
   图谱，其中部分终止子经过体外转录实验验证。补充材料 Table S2 提供了
   可直接使用的终止子坐标数据表，包含物种、染色体号、起止坐标、链方向、
   置信度打分（termite score）、IDR值、上下游基因关联、TransTermHP/RNAfold
   双重验证标志等字段。TERMITe覆盖的物种中，Listeria monocytogenes 和
   Enterococcus faecalis 不在上述 BATTER 论文13篇文献的物种清单中。

## 老板的要求（按时间顺序）

1. 最初要求：以 BATTER 论文 Table S1 中列出的13篇文献为起点，收集这些文献
   及其 Data Availability 声明中的原始/处理后转录终止位点数据，整理成
   标准化、可检索的数据库。

2. 后续追加：在此基础上进一步检索和补充外部数据来源，即在13篇文献
   之外寻找其他可能有价值的相关研究数据。

3. 最新明确：
   - 数据库需要以 Genome Browser（基因组浏览器）的形式展示，并结合其他
     基因组注释信息（如基因、CDS等）一并呈现；
   - 需要将整理成果撰写成一篇论文，投稿到专门发表数据类文章的期刊
     （举例：Scientific Data）。

## 目前的工作状态

  数据文件下载与内容验证（确认13篇均包含可直接使用的坐标数据）。
- 已开始检索 BATTER 未覆盖的物种/门类，或 BATTER 发表时间窗口之后新出现
  的相关研究，TERMITe 是目前找到的候选补充数据源之一，已完成对该文献的
  初步内容评估（物种覆盖、数据规模、坐标体系、字段结构等）。
- 尚未开始任何数据库搭建、格式转换或 Genome Browser 相关的实际开发工作，
  计划从 TERMITe 文献开始，并推广到 BTATTER 论文附表的其他文献。

## 最终需要达成的目标

1. 一个整合多篇文献真实实验数据（而非模型预测结果）的细菌转录终止子
   标准化数据库；
2. 一个基于该数据库、支持多物种切换、结合基因组注释信息的可视化/可检索
   Genome Browser 网站；
3. 一篇描述该数据库构建过程和数据内容的论文，符合数据类期刊
  （如 Scientific Data）的投稿要求。
