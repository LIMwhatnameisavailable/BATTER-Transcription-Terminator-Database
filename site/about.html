BTED

About the project关于项目

Purpose项目目的

BTED turns public bacterial transcript-end experiments into traceable records, downloadable tables, and genome-browser views.BTED 将公开细菌转录端点实验整理为可追溯记录、标准下载表和基因组浏览器视图。

Current release当前版本

v0.2.0 is a public demonstration release covering the 22 BATTER Table S1 source records. It is not a manuscript submission or long-term DOI archive.v0.2.0 是覆盖 BATTER Table S1 22 条来源的公开演示版本，不等同于论文投稿或 DOI 长期归档。
