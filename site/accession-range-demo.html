Important evidence boundary

A detected 3′ end is not automatically a functionally validated transcription terminator; it may also reflect RNA processing.

Interpretation

What do these records represent?

Both studies map their reported 3′ ends to the same reference assembly, so the coordinates can be viewed together. Their endpoint definitions and source identities remain independent.

    Suitable uses

    • Inspect endpoints relative to nearby genes
    • Compare agreement between independent studies
    • Export coordinates for downstream analysis

    Do not infer: that every record is a functional terminator.

    How does the genome browser load the data?

    The browser requests only the genomic region you are viewing, so a genome can open quickly without downloading every file in advance. This delivery detail does not change the endpoint coordinates or evidence labels.
