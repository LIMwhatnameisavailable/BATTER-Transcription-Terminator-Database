方法与局限

v0.1 local snapshot 是一个可审计的 Git 数据发布，而不是以网页替代原始数据仓库或浏览器的生产系统。

数据来源与标准化

来源来自 BATTER Table S1 覆盖的公开论文、补充材料和数据仓库。作者发表的端点表优先保留原始定义；原始信号派生的候选峰与文献整理记录被单独标识，不将它们重新表述为同一类证据。

BTED 以 1-based 生物学坐标保存单碱基端点，并同时提供规范 BED：start = position - 1，end = position。每个标准表使用相同 24 列 schema；每个 ID 保留来源、样本/记录层、contig、链与行序列身份。发布脚本检查坐标、链、BED、表头、行数和 SHA-256。

证据与发布规则

公开 release 仅使用 observed_signal、called_endpoint、author_called_endpoint 和 curated_record。作者整合的混合证据与纯预测不随公开端点下载发布；其可公开审计摘要仅记录文件指纹和排除理由。

源表、发布判定、处理记录和 checksum 由相同 source_id 关联。完整标准和字段定义在 docs/standards/。

局限性

  • 本版不复制原始测序、出版商 xlsx/PDF、参考序列、BigWig 或 JBrowse；原始数据链接和参考依据记录于逐来源 manifest。
  • 4 个 Lalanne 2018 来源是带坐标的文献整理记录，不能与作者直接发表端点或本库从信号调用的候选端点混为同层。
  • BATTER_S1_002 尚未公开端点表；其首要待办是对齐每个数据集级观察的样本、作者表行与坐标 provenance。
  • 个别来源仍保留物种命名、元数据或计数冲突；这些问题写入来源 README 和 manifest，不会被静默抹平。
