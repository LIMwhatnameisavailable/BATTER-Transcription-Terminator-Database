细菌转录 3′ End 数据库

BTED 将公开细菌转录 3′ 端实验整理为可追溯、可下载、可核验的标准化记录。本页是 GitHub Pages 发布索引；数据表和完整可复现性材料位于项目仓库。

v0.1 local snapshot

  • 22 个来源记录均已建立来源 manifest 与处理说明；它们对应 13 篇原始研究文献，两个数字代表不同统计单位。
  • 21 个来源、28,399 条记录已按统一 24 列 schema 发布到仓库 data/public/。
  • 17 个来源是作者发表的实验 3′ end 表，并附规范 BED；4 个来源是文献整理记录，仅发布 TSV。
  • BATTER_S1_002 维持仅审计状态，直至多技术汇总结果能按每条记录的实验 provenance 拆分。

逐来源发布状态见来源目录；本版完整边界、目录与下一步见仓库中的 发布说明。

证据边界

  • 公开端点层只接收实验信号、按公开规则调用的候选端点、作者发表端点和有明确范围的文献整理记录。
  • 纯计算预测，以及作者把预测和实验合并后不能拆分的表，不进入公开端点层或浏览器轨道。
  • “实验支持的 3′ end”不等于每一个位置都完成独立的终止功能实验；本站不把端点一律称为终止子。

完整定义见 证据分层与发布边界。

本版未包含的内容

  • 原始 FASTQ/BAM、出版商工作簿、参考 FASTA/GFF 与大轨道文件。请通过 GEO、SRA、ENA、ArrayExpress、Figshare 等原始入口获取。
  • JBrowse 和 BigWig。本地浏览器已用于处理核查，但应在后续作为独立的、版本化浏览器包发布，而不是随 Git 页面复制。
  • 服务端数据库、登录系统或私有数据访问。
